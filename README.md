## tp_python_clientserver_chat

Simple client serveur app

## Comment lancer le projet :

`python interface.py` avec GUI
`python client.py` dans le terminal


Modifications apportées

Ajout de commentaires pour expliquer le code
Ajout de vérifications pour le pseudo, l'IP et le port
Ajout de messages d'erreur quand le serveur ne répond pas
Ajout d'une interface avec Tkinter
Possibilité de rejoindre/créer un serveur depuis l'interface
Affichage des messages reçus dans la fenêtre
Possibilité d'envoyer des messages avec un bouton ou la touche Entrée
Ajout de couleurs et meilleur placement des champs

Bugs corrigés

Correction du problème avec socket.error
Correction du client qui ne se déconnectait pas correctement
Correction de la variable client qui n'était pas reconnue pour envoyer les messages
Correction de certaines erreurs quand le serveur est fermé
